# Compatibility Layer

Shared base for CarX Drift Racing Online 2 mods. Shows a "N mods loaded" line in the bottom-left corner of the screen.

Needs BepInEx 6 (IL2CPP) already installed in the game.

## Install

1. Download `CarXModManager.zip` from the [0.1-alpha release](https://github.com/david568303/Dro2-compatibility-layer/releases/tag/0.1-alpha).
2. Extract it into `<game folder>\BepInEx\plugins`.
3. Launch the game.

More details: [docs/DETAILS.md](docs/DETAILS.md)
